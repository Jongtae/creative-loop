AI 이미지 생성·수정

수정할 이미지는 먼저 업로드해야 하며, AI 입력·재사용 권한이 모두 필요합니다. 수정 결과는 새 이미지로 저장합니다.

자동 재호출 없음. 이미지 생성 후에도 텍스트·권리·브랜드 적합성을 직접 검토하세요. 최종 레이아웃의 문구는 작업실에서 별도 편집할 수 있습니다.

연결 상태

OpenAI API 키는 서버의 .env 파일에만 저장합니다. ALLOW_EXTERNAL_AI=1, OPENAI_API_KEY, OPENAI_MODEL(문구·분석), OPENAI_IMAGE_MODEL(이미지) 설정 후 서버를 재시작하세요.

자동 수집용 폴더 워처는 scripts/watch_imports.py를 참고하세요. 현재 앱은 인증·운영 체계가 완성된 공개 서비스가 아닙니다.
