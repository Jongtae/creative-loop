# 개발 백로그

이 문서는 남은 작업이다. 체크되지 않은 항목을 완료로 해석하지 않는다. 날짜는 고정하지 않았고, 실제 계정/데이터/예산을 확보한 뒤 일정화한다.

## 권장 순서

**M1 → M2 → M3**, 이후 M4/M5를 실제 데이터 규모에 맞춰 병행하고 M6는 사용자가 늘어날 때 진행한다. 페르소나 생성은 핵심 선행 의존성이 아니다.

GitHub 게시 후 `python scripts/create_github_issues.py`를 실행하면 아래 6개 이슈가 생성된다. 이 스크립트는 새 이슈만 만들고 기존 이슈 상태나 Projects 보드를 변경하지 않는다.

## [M1] 비공개 저장소 게시와 실제 HTTP 브라우저 검증

### 목표
준비된 로컬 MVP를 새 비공개 저장소에 게시하고 실제 네트워크 경로로 확인한다.

### 인수 조건
- [ ] `scripts/publish_github.sh`로 새 private repo 생성·push
- [ ] 기존 다른 저장소 변경 없음 확인
- [ ] GitHub Actions 테스트 통과
- [ ] `browser_smoke.py --transport network`로 10개 UI 흐름 통과
- [ ] Mac/Windows 대상 브라우저의 한글 렌더링·PNG 확인

현재 완료: 로컬 코드·69개 테스트·오프라인 Chromium 10개 검사. 원격 생성/배포는 미완료.

## [M2] 실제 AI 이미지 생성·수정·비전 파일럿

### 목표
코드 계약을 실제 API 계정에서 검증하고 디자이너가 품질·수정 효과를 판단한다.

### 인수 조건
- [ ] 서버 로컬 .env에 명시적 모델 설정; 키를 Git/채팅에 공유하지 않음
- [ ] 승인한 소량 호출로 신규 이미지, 원본 이미지 수정, 비전, 브리프 교정 각 1회 이상 확인
- [ ] 결과의 한국어/로고/제품 일관성·실제 크기·지연·usage 기록
- [ ] 이미지 생성 → SVG 조합 → 수동 교정 → 내보내기 전체 실행
- [ ] HTTP 401/429/거부/시간 초과 시 실패 표시 및 재호출 억제 확인
- [ ] 확정 비용 예산과 공급자 사용 제한 별도 설정

현재 상태: 어댑터와 모의 응답 테스트 있음. 유료 실호출·출력 품질은 아직 검증하지 않음.

## [M3] 허가된 소셜 데이터 소스 1개 연결

### 목표
광범위한 임의 크롤링 대신 사용권을 확보한 자사 채널 또는 계약 데이터 1개를 지속 반영한다.

### 인수 조건
- [ ] 공식 API와 승인 범위/목적/보존·삭제 정책 검토
- [ ] 노출·공유·댓글·저장 중 실제 제공되는 지표만 명시
- [ ] 업로드 이미지 또는 허용된 원본과 반응 스냅샷 연결
- [ ] 수집 창과 게시·관측 시각의 일관성 검증
- [ ] 페이지네이션/증분 수집/중복 방지/할당량/실패 재개 구현
- [ ] 사용자·플랫폼 삭제 요청 전파 및 별도 백업 처리 문서화
- [ ] 관측/생성/모델 입력 권한을 구분하고 API 통합 테스트

현재 상태: JSON/CSV/폴더 워처만 구현. API 인증과 소셜 자동 수집 없음.

## [M4] 의미 특징과 검색 품질 평가

### 목표
색상과 단순 레이아웃을 넘어 실제 크리에이티브 특성을 검색한다.

### 인수 조건
- [ ] 색·타이포·구성·피사체·카피·문화 맥락의 특징 사전 확정
- [ ] 이미지 임베딩 모델/가중치 라이선스 검토 후 1개 선택
- [ ] 한국어·영어 대표 자료와 사람 라벨로 오류/검색 정밀도 측정
- [ ] VLM 추론과 관찰 사실·불확실성 분리 저장
- [ ] 민감 인물 특성·신원 추론 금지
- [ ] 모델 버전/스키마 변경·재추출 정책

현재 상태: 픽셀 특징과 선택적 OpenAI 비전 어댑터만 있음. CLIP/SigLIP/PaddleOCR 등의 설치·성능 검증은 하지 않음.

## [M5] 인간 선택·실제 반응의 학습 평가 루프

### 목표
휴리스틱과 실증된 선호/성과 모델을 분리하고 생성·선택의 품질 개선을 검증한다.

### 인수 조건
- [ ] 디자인 품질·브랜드 적합·고객 반응·디자이너 선택 목표를 분리
- [ ] 평가에 쓰지 않을 학습/검증/시간 홀드아웃 명세
- [ ] 같은 카테고리·노출 조건과 유료/자연 유입, 게시자·예산 교란 확인
- [ ] 기본 템플릿/일반 AI/자료 요약/학습 모델 비교
- [ ] 순위 일치·선택률·불확실성·데이터 부족 기준 공개
- [ ] 실제 테스트되지 않은 성과 확률을 UI에 표시하지 않음
- [ ] 출시 결과와 예측의 오차를 저장하고 드리프트 확인

현재 상태: 한 로컬 디자이너의 6쌍부터 쓰는 작은 쌍대 모델. 소비자 선호나 CTR 예측은 없음.

## [M6] 디자인 도구 연동·운영 확장

### 목표
반복 제작에 필요한 편집 기능과 안전한 운영을 확장한다.

### 인수 조건
- [ ] 원본 보존·투명도 유지·로고/폰트 라이선스 정책
- [ ] 마스크 편집·텍스트 오탈자·세이프 영역·브랜드 금지 요소 점검
- [ ] Figma native editable layers / 디자인 시스템 연결 방식 확정·파일럿
- [ ] 다중 사용자 인증·인가·데이터 격리
- [ ] Postgres/객체 저장소/작업 큐/마이그레이션/조회 페이지네이션
- [ ] 분산 비용 한도, 감사 로그, 삭제/보존, 백업 복원, 보안 심사
- [ ] Docker 실제 빌드·실행 검증

현재 상태: 로컬 SQLite + SVG 내보내기. Figma API, 자유 레이어 편집, 다중 사용자 공개 서비스는 미구현.
