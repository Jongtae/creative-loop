# 제품 요구사항 / Creative Loop v0.1

## 제품 정의

브랜드 디자이너가 디자인 시안을 실제로 제작·교정·탐색·선택하는 작업실. 소셜 반응 DB는 연구 결과물을 출력하는 종착점이 아니라 **제작 과정의 참고 자료와 학습 데이터의 기반**이다.

고객군을 가상의 인격으로 꾸미는 기능은 핵심 경로에 두지 않는다. 현재 사용자는 단일 로컬 디자이너이며, 대상 산출물은 이미지 기반 정사각/세로/가로 SNS 크리에이티브다.

## 최우선 사용자 시나리오

브리프 작성 → 허가된 이미지 또는 AI 생성 초안 연결 → 12~60개 레이아웃 생성 → 원하는 시안의 카피/색/구성 교정 → A/B 선택 이유 기록 → 최종 후보 내보내기 → 이후 확보한 실제 반응 연결.

이미지와 반응 데이터가 없어도 기본 제작 경로는 실행돼야 한다. 없는 반응을 만들어 결과를 그럴듯하게 보이게 해서는 안 된다.

## v0.1 인수 기준

| ID | 기능 | 완료 기준 | 상태 |
|---|---|---|---|
| F01 | 이미지 입력 | 허용된 정지 이미지의 색상·크기 특징을 저장하고 사용권 기록 | 로컬 검증 |
| F02 | 관측 DB | 댓글·공유·노출, 출처·시각·허용 목적을 가져오고 중복 방지 | 로컬 검증 |
| F03 | 다중 시안 | 단일 브리프로 최대 60개 고유 파라미터 SVG를 생성 | 로컬 검증 |
| F04 | 편집 | 카피/색/레이아웃/글자 크기 변경, 버전 보존·충돌 거부 | 로컬 검증 |
| F05 | 선택 | 두 시안의 선택과 이유 저장, 최종 후보 표시 | 로컬 검증 |
| F06 | 산출물 | SVG/JSON 및 브라우저 PNG, 후보 ZIP | 로컬 검증 |
| F07 | 근거 | 실제·동일 조건의 관측만 검색하고 출처를 명시 | API 테스트 |
| F08 | 개인 선택 정렬 | 6쌍 이상의 선택을 별도 학습; 고객 예측과 구분 | API 테스트 |
| F09 | AI 어댑터 | 이미지 생성·수정, 문구 교정·비전 입력을 명시적 동의 뒤 호출 | 모의 응답 계약 테스트; 실호출 대기 |
| F10 | 배포 준비 | 실행 문서, 원문, 테스트, CI, 비공개 GitHub 게시 스크립트 | 로컬 파일 준비; 원격 게시 대기 |

‘고유 시안’은 레이아웃/색/모티프/폰트 배율 파라미터의 차이를 뜻한다. 사람에게 충분히 다른 고품질 디자인으로 보이는지는 별도 디자인 리뷰가 필요하다.

## 이번 릴리스의 비목표

모든 SNS의 실시간 수집, 동영상 생성·편집, 노출 알고리즘의 인과 보정, 소비자 선호/매출/전환 예측, 실제 페르소나 에이전트, 특정 디자이너 스타일의 파인튜닝, Figma 원격 파일 수정, 다중 사용자 SaaS 운영.

## 파일럿 성공 지표 — 목표이지 측정된 결과 아님

동일한 브리프 묶음을 사람이 평소 방식으로 제작한 경우와 이 도구를 사용한 경우로 비교한다. 첫 유효 후보까지 걸린 시간, 실제 채택률, 교정 횟수, 산출물 오류율, 브랜드 가이드 준수 여부, 한 작업당 AI 비용을 기록한다. 관측된 좋아요나 공유가 높다는 이유만으로 디자인 품질이 우수하다고 판정하지 않는다.

처음에는 전문가 1~3명의 사용성 파일럿으로 결함을 찾는다. 효과를 주장할 평가 실험은 브리프·디자이너·순서 효과, 표본 크기와 결과 지표를 별도로 설계한다. 소규모 테스트나 합성 사용자 수를 통계적 검증 완료로 표현하지 않는다.
